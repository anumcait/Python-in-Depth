# Mission Python 100 — Zero to Hero

A free, GitHub-friendly 100-day Python learning course. Start with `day-01.md`, then work sequentially. Each chapter includes a runnable example, interpretation, real-world engineering considerations, exercises, and review. The later chapters introduce optional third-party dependencies and infrastructure; they are not a substitute for building and testing a full production service.

## Learning phases

| Days | Focus |
|---|---|
| 01–20 | Language foundations and collections |
| 21–40 | Python professional skills and OOP |
| 41–60 | Testing, tooling, algorithms and concurrency |
| 61–80 | Web APIs, databases, security and architecture |
| 81–90 | Fashion marketplace, ride-booking and system design |
| 91–100 | Data, ML, GenAI, Docker, CI/CD, AWS and capstone |

## Study approach
Read the theory, predict code behavior, run and modify the sample, deliberately break it, then complete the mini-project. These chapters are a structured first edition; they are not yet all as expansive as the original Day 01 reference chapter.
